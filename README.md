# natalie

Static personal calendar with Death Note and Pusheen themes.

Open index.html through a static server. No install or build step is required.

GitHub Pages serves the main branch from the repository root. All assets use relative paths and .nojekyll disables Jekyll processing.

The first three pages are always available. The following 32 messages unlock daily from 26 October through 26 November 2026 using Europe/Rome dates. Add ?anteprima=1 to preview every page. The date check and messages are client-side.

Edit messages.js to change the text. Both themes share the same messages.
